# 2026-10-27 — SwiftKeychain 0.1.0

- **Shipped:** `KeychainAccess`, `KeychainItem`, `KeychainError`; `SystemKeychain` (data-protection
  or login keychain) and `InMemoryKeychain`, held to one contract by the same tests; `KeychainKey`;
  `KeychainTokenCache` (trait `CLIAuth`) and `KeychainClientStorage` (trait `OAuth`); the guide
  "Choosing Where Secrets Live". Closes Stack Map gap #7.
- **Tests:** 31 with both traits (13 without); the contract runs against the real login keychain.
- **Corrected while building:** the proposal said an app using one adapter wouldn't resolve the
  other; SwiftPM resolves every package-level dependency. Traits fix it, verified in a scratch
  package. The gate couldn't build with traits, so quality-gate-swift learned them (#63).
- **Found:** the data-protection keychain refuses an unsigned process's store as
  `missingEntitlement` but answers its reads "not found".
- **Not done:** no implementation checklist was kept for this release; the proposal, its §17 and
  this summary are the record.
- **Next:** `SecAccessControl` with user presence; SwiftIdentity `SealingKey(data:)`/`Pepper(data:)`;
  moving SwiftMCPClient and FleetWatch onto this package.
